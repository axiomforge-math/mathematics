# Instructions for Gemini

Read and follow [AGENTS.md](AGENTS.md): it is the canonical instruction set of this
repository. The critical rules, restated:

1. This is the public archive of AxiomForge. Add only public content: never reference
   unpublished work, internal tooling or identifiers, local paths or credentials.
2. Never weaken a check, a gate or the Lean trust policy (`propext`, `Classical.choice`,
   `Quot.sound` only; no `sorry`, `admit`, `axiom`, `native_decide`).
3. Never upgrade a verification status in `result.toml` without the evidence.
4. Each contribution in `results/` is self-contained; `catalogue/` is generated by
   `python3 scripts/afm.py catalogue`.
5. MSC2020 classification and an exact AI disclosure are mandatory.
6. Never read or commit `.env`; commit or push only when the owners ask.
