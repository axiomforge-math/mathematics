# Research logs

The curated history of AF-0002: how the result was found, what failed, what was computed and how
everything was verified. These files are written for readers. Every claim in them is either
supported by a file of this contribution or marked as unverified.

| File | Content |
|---|---|
| `timeline.md` | dated milestones from the first idea to this preprint |
| `insights.md` | the ideas that made the proof work, and why |
| `obstructions.md` | approaches that failed, and the precise reason |
| `attempts/NNN-<short-title>.md` | superseded or failed approaches |
| `experiments/` | programs, certificate data and their recorded outputs (see `experiments/README.md`) |
| `verification.md` | every check performed: what, how, outcome, command |
| `ai-contributions.md` | the role of every AI system (GPT-6.2 XHigh (web version); Claude Opus 5.5, Claude Fable 5.2 and Claude Sonnet 5.5 (Anthropic)) and of the people involved |

Status words follow the archive's verification policy: *proved*, *candidate*, *heuristic*,
*numerical evidence*, *refuted*. A log never upgrades the status of a statement; `result.toml`
and the manuscript are authoritative.
